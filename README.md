# med-ai-journey 🩺

> 一名大四医学生（昆明医科大学 · 临床医学）的「医学 × AI」学习档案。
>
> **目标**：2027 寒假拿下第一段医疗大模型数据/评测岗实习 → 之后全力考研。
>
> **路径**：Python 基础 → 数据分析（pandas）→ 医疗大模型评测 → 中文医疗 NLP → 实体抽取工程 → 可复现作品。
>
> **节奏**：D 编号记录学习与验收证据；每 6 个技术节点后做一次周报。任务内容根据真实表现调整，GitHub 在里程碑时整理更新。

## 🎯 核心作品：《医学大模型基础能力评测集 v2》 → [`week4/`](week4/)

48 道医学单选题（诊断 / 用药 / 指南 / 伦理 各 12），完整跑通「构建 → 双模型交叉验证 → 人工终审 → 异源评测 → 报告」全流程：

| 环节 | 做法与结果 |
|---|---|
| 出题 | 执医真题改编 + 指南原文检索，每题锚定出处 |
| 答案键质控 | 双模型交叉验证 44/48 一致，4 题分歧经**教材原文人工终审** |
| 正式评测 | 通义千问（异源判分设计）→ 准确率 **85.4%** / 平均 **8.54/10** |
| 关键发现 | 同模型两次作答 **12.5% 不稳定**；「真实数字放错位置」类幻觉；指南维度 66.7% 塌方（7 题错 4 全是精确数字） |

📄 报告与数据全开源：`评测报告_通义千问.md` · `依据判定表_助手初判.csv` · `指南原文_待审核_8_11_12.md` · `eval_records.csv`

- [KUAKE-QIC 提分](week5/29_day29_CBLUE提分.ipynb)：开发集准确率 **76.68%**。
