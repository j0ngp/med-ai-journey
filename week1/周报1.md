## 三、本周踩坑清单（16 条，亲身踩过）

1. 中文全角标点（（）""，）会导致 SyntaxError——写代码先切英文输入法
2. 用了没赋值的变量 → NameError
3. `print("name")` 打印的是文字本身，打印变量值不加引号
4. `4.8 in (3.5, 5.5)` 是"元素判断"不是"区间判断"；区间用 `3.5 <= x <= 5.5`
5. 别用 Python 内置名字当变量名（range、list、max…）
6. Jupyter 变量跨单元格残留——报错怪异先 Kernel → Restart Kernel
7. 圆括号 = 调用函数；方括号 = 取元素（`labs.append("CRP")` 不是 `append["CRP"]`）
8. `return` 把结果交给程序；`print` 只显示给人看
9. 临床阈值要想清楚边界：`<` 还是 `<=`，差一个等号诊断就不同
10. 带小数的数据用 `float()`，`int("22.5")` 会崩
11. `return "a", "b"` 返回元组；拼句子用 `+` 或 f-string
12. for 拆元组：`for w, h in patients:`
13. f-string：`f"BMI {bmi}，{level}"`
14. 函数调用忘写括号（`bmi_calc` vs `bmi_calc(...)`）——不报错但结果错，写完必测
15. `except` 要写错误类型：`except ValueError:`
16. 重启内核后函数要重新运行；遇到 NameError 先检查定义跑了没
