## 三、本周踩坑清单（新增）

1. `header=None` 配合 `names=[...]` 读无表头文件（否则第一行数据被当列名）
2. 医学数据"假 0"：血糖/血压/BMI 的 0 其实是缺失值，需用医学常识识别后替换为 NaN
3. Jupyter 只显示"最后一行表达式"，赋值语句（`x = ...`）不显示 → 补裸变量名
4. 内核重启后变量清零：报 NameError 先看 In[ ] 编号是不是 In[1]
5. pandas 两列比较按"索引"对齐：索引对不上报 `Can only compare identically-labeled` → `reset_index(drop=True)`
6. `(True/False 串).astype(int)` 变 1/0，配合 `.mean()` 就是准确率
7. Kaggle 提交要求 418 行（官方 test 集），练习用的 91 行文件会被拒
8. 出题必须自己核验答案 + 写出处：评测集的答案错误 = 整个作品失去可信度
9. `df.to_csv(..., index=False, encoding="utf-8-sig")`：-sig 防 Excel 中文乱码
10. 指南类题目数字必须查权威指南原文，不能凭记忆（亲历：连模型自己都会答错）
