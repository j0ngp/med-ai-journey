# 赛题十三实体标注规范 v1（工作草案）

> 更新：2026-09-09
> 状态：个人练习形成的暂定规则，尚未经过官方样例或权威术语规范验证。

## 使用原则

1. 官方任务说明、官方样例和正式数据字典优先于本草案。
2. 医学类别结合上下文判断；依据不足时进入待复核，不把经验判断写成权威结论。
3. 实体边界尽量覆盖能够独立表达目标概念的最小连续文本。
4. 每次规则修订保留例子和原因，避免为了单个样本临时改变口径。

## 四类易混点

### 1. 六经病名

- 当前例子：`太阳病，头痛发热……`
- 暂定处理：当“太阳病”作为疾病名称出现时，标为`疾病`；“头痛”“发热”等另标为`症状`。
- 使用边界：这条规则目前只完成了“太阳病”例子的判断，不能自动推广为所有六经词的已证实规则。
- 待核验：教材中的术语归属、官方类别定义，以及“少阴病”等样例的实际标签。

### 2. 阴阳虚：证候与病机

- 明确作为辨证结果时，暂标为`证候`。
- 明确用于解释症状产生的原因或病理机制时，暂标为`病机`。
- 上下文不足时进入待复核，不只凭“阳虚”“阴虚”的词形固定分类。
- 待核验：官方是否允许同一文本在不同语境下使用不同类别。

### 3. 复合症状切分

- 拆开后的各部分都能完整、独立表达症状，且彼此为并列关系时，分别标注。
- 整个表达能够完整表示一个症状，拆开后含义不清时，保留整体。
- 无法判断各部分是否独立完整时，进入待复核。
- 当前暂定：`头晕目眩` → `[头晕][目眩]`；`汗出恶风` → `[汗出][恶风]`。

### 4. 炮制字与药名

- 炮制字与药名组成具体药物名称时，整体暂标为`中药`：`[炙甘草/中药]`。
- 炮制字在句中明确表示处理动作时，单独标为`炮制`：`[甘草/中药]，[炙/炮制]用`。
- 删除检验：删去“用”后，“炙”仍能表达炮制方法，因此“炙用”中的最小炮制实体暂定为“炙”。
- 若官方不允许重叠实体，`炙甘草`只保留整体中药标注，不再重复标“炙”为炮制。
- 待核验：官方是否允许嵌套/重叠实体，以及官方样例对炮制药名的边界处理。

## 字符位置约定

当前练习使用 Python 的 0-based 半开区间`[start, end)`：

```python
start = sentence.find(text)
end = start + len(text)
assert sentence[start:end] == text
```

- `start`是文本第一次出现的位置。
- `end`是最后一个字符的后一位，不包含在切片中。
- `find`找不到文本时返回`-1`；当前练习函数将其转换成`(None, None)`。
- `find`只返回第一次匹配，不能直接处理同一实体重复出现的情况。

正式数据下发后，需要用2–3条官方样例确认索引是0-based还是1-based、结束位置是闭区间还是半开区间，再修改导出逻辑。
